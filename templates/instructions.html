Overview

The AI Data Normalizer (AIDN) is a powerful web-based application designed to help accountants and data professionals automatically process, clean, and transform spreadsheet data using natural language commands and AI-powered automation.

What Makes AIDN Special?
  • Natural Language Processing: Describe what you want in plain English
  • AI-Powered Automation: Advanced algorithms understand and execute complex data transformations
  • Multi-Format Support: Handles Excel (.xlsx, .xls) and CSV files seamlessly
  • Real-Time Processing: See changes instantly with visual feedback
  • Template Transformation: Apply templates to restructure entire datasets

Getting Started

1
Access the Application

Open your web browser and navigate to http://127.0.0.1:8000 to access AIDN.

2
Upload Your Spreadsheet

Click the "Choose File" button in the left sidebar and select your Excel or CSV file. Supported formats:

  • .xlsx - Excel 2007+ format
  • .xls - Legacy Excel format
  • .csv - Comma-separated values
3
Review Your Data

Once uploaded, your spreadsheet will appear in the main viewing area. You can:

  • Scroll through your data
  • View multiple sheets (if available)
  • Inspect data structure and formatting
4
Start Processing

Use the command interface to describe what you want to do with your data in natural language.

Workflow Guide

Method 1: AI Command Processing

1
Upload Your Data

Use the file input in the sidebar to upload your spreadsheet. The system will automatically:

  • Detect file format and encoding
  • Process merged cells and formatting
  • Handle multiple sheets
  • Check for existing mappings
2
Enter Natural Language Commands

In the command interface, describe what you want to do. Be specific but natural:

Good Examples:
  • "Create a new column called 'Full Name' by combining First Name and Last Name columns"
  • "Filter out all rows where the Amount column is less than 100"
  • "Sort the data by Date column in descending order"
  • "Calculate the percentage of each row's amount relative to the total"
3
Review and Execute

Click "Enter" or press Enter to process the command. The AI will:

  • Generate appropriate Python code
  • Execute the transformation
  • Update the spreadsheet view
  • Save the change to history

Method 2: Template Transformation

1
Enter Split View Mode

Click the Split View button Alt+Shift+S to view your data and template side by side.

2
Create Your Template

Edit the right side to show the desired structure. You can:

  • Rename columns
  • Rearrange column order
  • Set constant values
  • Create sequences (1, 2, 3...)
  • Generate date series
3
Apply Transformation

Use "Update Template" Alt+Shift+U to capture your template, then "Transform to Template" Alt+Shift+T to apply it to your entire dataset.

Troubleshooting

File Upload Errors

Error: "No selected file" or upload fails

Common causes: File format issues, size limits, browser restrictions
Solutions:
  • Ensure file format is supported (.xlsx, .xls, .csv)
  • Check file size - large files may take longer to process
  • Verify file is not corrupted or password-protected
  • Close file in Excel before uploading
  • Try refreshing the page and uploading again
Command Processing Issues

Error: "Unable to complete your request" or processing fails

The system couldn't understand or execute your command properly
Solutions:
  • Check that column names in your command match exactly (case-sensitive)
  • Ensure data types are compatible with the operation
  • Verify there's enough data to perform the operation
  • Try breaking complex commands into smaller steps
  • Use the undo function and rephrase your command
Connection Error

Error: "Unable to connect" or "Service temporarily unavailable"

Communication issues with the processing service
Solutions:
  • Check your internet connection
  • Refresh the page and try again
  • Clear browser temporary files and cookies
  • Try using a different browser
  • Contact support if error persists
Template Setup Issues

Error: "Template area is empty" or template configuration problems

Issues with split view setup or template creation
Solutions:
  • Ensure you're in split view mode before creating templates
  • Add at least one row of sample data in the right panel
  • Update template before attempting transformation
  • Check that column headers are properly defined
  • Verify data patterns are supported (sequences, constants, etc.)
History Access Issues

Error: "History not found" or command history problems

Issues accessing or saving your command history
Solutions:
  • Check if browser allows data storage for this site
  • Use storage cleanup to reset command history
  • Ensure browser has sufficient storage space
  • Try accessing from a different location
Performance Issues

Problem: Slow processing or interface freezing

System resource limitations or large dataset processing
Solutions:
  • Reduce file size by splitting large datasets
  • Close other browser tabs to free memory
  • Use Chrome or Edge for better performance
  • Process complex operations in smaller batches
  • Clear browser temporary files and restart browser
Need More Help?

If you continue to experience issues:

  • Take screenshots of error messages
  • Note the exact steps that led to the error
  • Try reproducing the issue with a smaller test file
  • Contact technical support with detailed information
  • Report any unusual behavior through official channels

Best Practices

Writing Effective Commands
  • Be Specific: Use exact column names as they appear
  • One Task Per Command: Break complex operations into steps
  • Use Examples: "Like this..." or "Similar to..."
  • Specify Location: "In column X" or "For rows where..."
  • Check Data Types: Ensure operations match data types
Data Preparation
  • Clean Headers: Remove special characters from column names
  • Consistent Formatting: Standardize date and number formats
  • Remove Empty Rows: Clear unnecessary blank rows
  • Backup Original: Keep a copy of your original file
  • Test with Small Sets: Try commands on a subset first
Performance Optimization
  • Batch Similar Operations: Group related commands
  • Use Mappings: Automate repetitive workflows
  • Monitor Token Usage: Optimize costs with analytics
  • Save Prompts: Reuse successful commands
  • Regular Cleanup: Clear temporary files periodically
Data Security
  • Local Processing: Data is processed locally
  • Temporary Storage: Files are automatically cleaned up
  • No Cloud Sync: Data doesn't leave your environment
  • Session Isolation: Each session is independent
  • Download Immediately: Save results promptly
